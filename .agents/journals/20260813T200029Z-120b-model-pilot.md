## Problems Encountered

- The first 20B preflight answer reasoned correctly but truncated a nested JSON
  string. The suite retained one structured-output test and changed unrelated
  answers to canonical delimiter formats to avoid over-weighting quote escaping.
- The first Luna preflight failed before spawn because `--ask-for-approval` was
  placed after the `exec` subcommand. The runner was repaired and the preflight
  Agent Dispatch run was closed with a passing lifecycle audit.
- The initial ambiguity scorer required an exact `record class` substring and
  under-credited valid variants such as `record/data class`. The scorer was
  generalized to explicit accepted concept alternatives and all saved results
  were deterministically rescored.
- 120B cold startup took 175.722 seconds. Two later requests reached the fixed
  180-second local timeout. The batch stopped after the second consecutive
  failure per local-reasoning policy. An already-started sixth invocation
  completed after termination, but its response was unavailable for scoring;
  its local outcome was explicitly recorded as rejected.
- The local wrapper returned a nonzero command before exposing failed invocation
  IDs to the runner. The raw local-reasoning ledger preserved those IDs and
  durations, and the saved result artifact was reconciled from that metadata.
- The first journal sidecar predated the harder suite and later harness edits;
  a second sidecar was required to preserve a complete mutation history.
- A pre-push privacy scan found local user paths in four generated failure
  details. They were replaced with equivalent path-independent diagnostics.

## Lessons

- The present easy-to-moderate suite is useful for operational characterization
  but too easy to establish remote-tier reasoning equivalence: all complete
  routes hit the quality ceiling.
- Local 20B is an exceptionally strong route for bounded synthetic tasks on
  this host: it matched the three remote baselines while completing the suite
  faster and consuming no remote credits.
- 120B demonstrated correct bounded reasoning on three tasks, but the current
  32k-context, 180-second profile is not reliable enough for automatic regular
  use.
- A dedicated 120B execution profile should reduce context, extend timeout, and
  guarantee exclusive scheduling and cancellation drain before a harder pilot.
- Actual operational token consumption differs sharply across interfaces
  because remote Codex executions include their own system context; route-level
  costs should not be described as tokenizer-normalized model efficiency.
- Generated benchmark failures should retain the failure class and exit status
  without embedding machine-specific executable paths.
